# e-Return Helper — আয়কর রিটার্ন অনুশীলনের ডেমো

বাংলাদেশের **NBR e-Return (etaxnbr.gov.bd)** সাইটের হুবহু চেহারার একটা **অফলাইন অনুশীলন সাইট**।
যত খুশি মক ডেটা দিয়ে অনুশীলন করুন, প্রতিটি ঘরের মানে বাংলায় বুঝুন, কর কত হচ্ছে সাথে সাথে দেখুন —
তারপর সেটা দেখে দেখে আসল সাইটে বসান।

> ⚠️ **এটি NBR-এর সাইট নয়, কোনো সরকারি সাইটও নয়।** এখানে যা লিখবেন তা কোথাও পাঠানো হয় না —
> শুধু আপনার নিজের ব্রাউজারে থাকে। আসল রিটার্ন জমা দিতে হবে **etaxnbr.gov.bd**-তে।

---

## চালু করা — যে কেউ পারবেন

পুরো ফোল্ডারটা কপি করে যেকোনো কম্পিউটারে রাখুন, তারপর:

**সবচেয়ে সহজ:** `START.bat` ডাবল-ক্লিক করুন।
Node থাকলে সার্ভার চালু করে ব্রাউজার খুলে দেবে; না থাকলে সরাসরি ফাইল খুলবে।

**নিজে চালাতে চাইলে:**
```
node server.js
```
তারপর ব্রাউজারে **http://localhost:5173**

**Node ছাড়া:** `index.html`-এ ডাবল-ক্লিক করলেও সব কাজ করে —
শুধু Ask AI-এর *অনলাইন* উত্তর ব্রাউজার আটকাতে পারে (অফলাইন উত্তর ঠিকই আসবে)।

| | |
|---|---|
| ইনস্টল | কিছু না — npm install নেই, বিল্ড নেই |
| ইন্টারনেট | লাগে না (শুধু অনলাইন AI চাইলে) |
| Node | ঐচ্ছিক |
| API key | ঐচ্ছিক — key ছাড়াও Ask AI অফলাইনে উত্তর দেয় |
| ডেটা | সব শুধু আপনার ব্রাউজারে (localStorage) |

## আপনার তথ্য কোথায় থাকে

- **নিজে থেকেই সেভ হয়** — কিছু লিখলেই সাথে সাথে, কোনো Save বোতাম চাপতে হয় না
- **শুধু আপনার কম্পিউটারে** — ব্রাউজারের localStorage-এ; ইন্টারনেটে যায় না, NBR-এ যায় না
- **পরে এসে আবার পাবেন** — ব্রাউজার বন্ধ করে কাল-পরশু খুললেও সব আগের মতো, Ask AI-এর কথোপকথনসহ
- **ব্যাকআপ** — "সেভ ফাইল" দিয়ে `.json` নামিয়ে রাখুন; অন্য পিসিতে "ফাইল লোড" দিয়ে ফিরিয়ে আনুন
- **যেভাবে হারাতে পারে** — ব্রাউজার ডেটা মুছলে, অন্য ব্রাউজার/পিসিতে খুললে, বা ইনকগনিটোতে কাজ করলে

## প্রতিটি ঘরে যে সাহায্য আছে

ঘরের পাশে `?` চাপলে ডানে খোলে:

- 🧾 **কর হিসাবে যায় কি না** · ⬆️⬇️ **বেশি দিলে কর বাড়ে না কমে**
- 📖 এটা কী · 📄 সংখ্যাটা কোথায় পাবেন · 🧮 কীভাবে হিসাব করবেন
- 📊 সাধারণত কেমন হয় (যেমন: মূল বেতন মোট বেতনের ৫০–৬০%, বাড়ি ভাড়া মূল বেতনের ৫০%)
- 💡 উদাহরণ · ⚠️ যে ভুলটা সবাই করে · ⭐ টিপস
- 🎯 **কোনটা বাছবেন** — প্রতিটি ড্রপডাউনের প্রতিটি অপশনের জন্য "কখন" ও "কেন"
- 🔗 **কীসের সাথে মিলতে হবে** — স্যালারি সনদ, ব্যাংক সনদ, নাকি গত বছরের রিটার্ন
- `➜ ঘরটি দেখান` — সরাসরি ওই ঘরে নিয়ে গিয়ে কমলা তীর দিয়ে দেখায়

## অস্বাভাবিক অঙ্ক ধরার ব্যবস্থা

টাইপ করার সাথে সাথেই ঘরের নিচে সতর্কবার্তা আসে, উপরে ব্যাজে মোট সংখ্যা:

- ⛔ **ঠিক না করলে লাইভে আটকাবে** — ব্যালান্স শিট মেলেনি, তহবিলে ঘাটতি, খরচ ০,
  Location দেওয়া হয়নি, "গাড়ি আছে" বলেছেন কিন্তু সম্পদে গাড়ি নেই
- ⚠️ **যাচাই করুন** — মাসিক অঙ্ক লিখে ফেলেছেন (বার্ষিক লিখতে হয়), বাড়ি ভাড়া মূল বেতনের চেয়ে বেশি,
  DPS ১,২০,০০০ ছাড়িয়েছে, বীমা প্রিমিয়াম পলিসি মূল্যের ১০%-এর বেশি, সুদের হার ২০%+,
  খরচ আয়ের ২০%-এর কম, গত বছরের নিট সম্পদ ০
- 💡 **সুযোগ** — উৎসে কাটা কর দাবি করা হয়নি
- **পাতায় পাতায় মিল** — Rebate-এ DPS আছে কিন্তু সম্পদে নেই, ব্যাংক সুদ আছে কিন্তু ব্যালান্স ০

## Ask AI

key ছাড়াও চলে — সব ফিল্ডের ব্যাখ্যা, নিয়ম ও আপনার বর্তমান সংখ্যা বিল্ট-ইন আছে।

AI-কে একসাথে দেওয়া হয় **পাঁচটি জ্ঞানভাণ্ডার**:

1. `js/sitemap.js` — লাইভ সাইটের পূর্ণ ডিজাইন-মানচিত্র (পাতা → সেকশন → ঘর → অপশন)
2. `js/knowledge.js` — বাস্তব পূরণের ধাপ, মানুষ যেখানে আটকায়, আর **"আমার X আছে — কোথায় দেখাব?"**
   রাউটিং টেবিল (গরুর খামার, রেমিট্যান্স, ফ্রিল্যান্সিং, পেনশন, উবার, স্বর্ণ, উত্তরাধিকার — ২১টি পরিস্থিতি)
3. `js/choices.js` — ২৩টি ড্রপডাউনের প্রতিটি অপশনে "কখন / কেন"
4. `js/reference.js` — PSR, সময়সীমা, জরিমানা, কাগজের চেকলিস্ট, TDS, সারচার্জ, FAQ
5. আপনার এখনকার সংখ্যা + ডেমো যেসব অসঙ্গতি ধরেছে

**ফলব্যাক চেইন:** Gemini key-১ → key-২ → … → Groq। প্রতিটি key-এর মডেল **ListModels দিয়ে নিজে
খুঁজে নেয়** — নতুন মডেল এলে নিজেই ধরে, কোটা শেষ (429) হলে ওই key ২০ মিনিট বাদ দিয়ে পরেরটায় যায়।

**কথোপকথন হারায় না** — পাতা বদলালে, minimise করলে, ব্রাউজার বন্ধ করে আবার খুললেও থাকে।

### উত্তর নির্ভুল রাখতে

1. **কঠোর নির্দেশ** — জ্ঞানভাণ্ডারের বাইরের কিছু বলা নিষেধ; জানা না থাকলে সোজা
   *"এটা ডেমোর জ্ঞানভাণ্ডারে নেই — NBR/কর আইনজীবীর কাছে যাচাই করুন"*
2. **temperature 0.05**
3. **কোড দিয়ে যাচাই** — ভুয়া নেভিগেশন লিংক বাদ; করমুক্ত সীমা বা রেয়াতের হার ভুল বললে
   নিচে সংশোধনী (বাংলা ও ইংরেজি দুই ধরনের অঙ্কই ধরে)
4. **প্রতিটি উত্তরে উৎস** — "লাইভে Tax & Payment-এর সংখ্যার সাথে মিলিয়ে নিন"
5. **দ্বিমতে এক পক্ষ নেয় না**

### নিজের API key যোগ করা (ঐচ্ছিক)

## কর নিয়ম (করবর্ষ ২০২৬-২০২৭)

আয়বর্ষ ০১-০৭-২০২৫ — ৩০-০৬-২০২৬। ডিফল্ট মান:

- করমুক্ত সীমা: সাধারণ ৪,০০,০০০ | নারী ও ৬৫+ ৪,৫০,০০০ | প্রতিবন্ধী/তৃতীয় লিঙ্গ ৫,২৫,০০০ | মুক্তিযোদ্ধা ৫,৫০,০০০
- স্ল্যাব: পরবর্তী ৩ লাখ ১০% → ৪ লাখ ১৫% → ৫ লাখ ২০% → ২০ লাখ ২৫% → বাকি ৩০%
- বেতন ছাড় (বেসরকারি): মোট বেতনের ১/৩ বা ৫,০০,০০০ — যেটি কম
- বিনিয়োগ রেয়াত: সর্বনিম্ন { বিনিয়োগের ১০%, মোট আয়ের ৩%, ৭,৫০,০০০ }
  → **সর্বোচ্চ রেয়াতের জন্য আয়ের ~৩০% বিনিয়োগই যথেষ্ট**
- ন্যূনতম কর: ৫,০০০ (নতুন করদাতা ১,০০০)
- সারচার্জ: নিট সম্পদ ৪ কোটি পর্যন্ত ০ → ১০% → ২০% → ৩০% → ৩৫%;
  একাধিক গাড়ি বা ৮০০০+ বর্গফুট বাড়ি থাকলে ন্যূনতম ১০%

⚠️ প্রকাশিত উৎসে কিছু অমিল আছে (করমুক্ত সীমা ৩,৭৫,০০০ বনাম ৪,০০,০০০; রেয়াত ১৫% বনাম ১০%)।
এখানে **Finance Act 2026** অনুযায়ী ধরা হয়েছে। লাইভ eReturn-এর Tax & Payment পাতার সংখ্যার সাথে
মিলিয়ে নিন — না মিললে **কর নীতিমালা** পাতা থেকে বদলে নিলেই হিসাব ঠিক হয়ে যাবে।

  TDS সনদ, ব্যাংক সুদ সনদ) থাকতে হবে। ভুয়া কাগজ দিলে জরিমানা ও শাস্তি দুটোই হয়
